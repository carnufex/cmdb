# Runbook: strömavbrott eller reservkraft (syntetisk)

Gäller när en uppringare rapporterar strömavbrott, larm från likriktaren eller att stationen går på batteri.

1. Bekräfta stationen och verifiera uppringaren.
2. Fråga om nätströmmen är borta i området, eller bara på stationen. Fråga också hur länge det har pågått.
3. Om stationen går på batteri: batterierna räcker normalt 2–4 timmar. Äldre batterier kan räcka betydligt kortare.
4. Kontrollera likriktarens larmpanel och säkringarna i elcentralen. Återställ inga säkringar som löser ut igen.
5. Kör påverkansanalysen för stationen. Den visar vad som faller när batteriet tar slut.
6. Skapa ärendet med uppskattad batteritid. Vid P1 larmas jouren, som beslutar om mobilt reservkraftverk.
