## Bakgrund
GitHub Actions är inte tillgängligt för kontot just nu. Verifieringen körs därför som ett skript som är identiskt lokalt och i en framtida CI-runner, så att ett workflow blir en tunn wrapper när det går att aktivera.

## Acceptanskriterier
- [ ] `scripts/verify.sh` bygger, testar (inklusive Testcontainers) och lintar api och web, och avslutar med felkod vid fel
- [ ] Containerbygge verifieras (`--images`)
- [ ] Dokumenterat i README och CONTRIBUTING som krav före PR
- [ ] Inget GitHub Actions-workflow läggs till förrän kontot tillåter det (eget issue då)
