# Backlog

Källfiler för de första issues. Skapas på GitHub av `scripts/bootstrap-github.sh`. Efter det är **GitHub-issues sanningskällan**, och de här filerna uppdateras inte.

Format: front matter med `title`, `labels` (kommaseparerade) och `milestone`, sedan brödtext i markdown. `#{{NN}}` ersätts med issuenumret för fil `NN-*.md`.
